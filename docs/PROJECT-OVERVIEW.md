# PhaseGate | Project overview
[← Back to the command center](../README.md) · [Start here](START-HERE.md) · [Engineering](engineering/PG-01-architecture.md)

> **DPN Technology / Advanced Research** — Project PhaseGate asks whether intact macroscopic objects could ever be transferred between disconnected physical locations in both directions. This is a scientific investigation of a currently unverified capability, **not** an existing teleportation system.

## The idea in one minute

| Vision | Current reality | Our responsible next step |
|:--|:--|:--|
| Object enters **Gate A**, exits **Gate B**, and the reverse | No verified science demonstrates an operational physical matter portal | Study the physics and develop **PG-01**, a paired **measurement** system for scientific controls |

**What success would eventually require:** independent proof that the same object crossed, that no hidden ordinary route or replacement explains the observation, that timing and evidence are sound, and that external teams can reproduce it.

**What success does not mean:** paired video displays, optical portals, a digital twin, quantum state teleportation, CGI, concealed transportation, or simulator behavior. None demonstrates intact object transfer.

## Three coordinated programs

| Workstream | Delivers | What it does **not** claim |
|---|---|---|
| **Scientific research** | Annotated papers, falsifiable physical hypotheses, competing explanations | A demonstrated method to construct wormholes |
| **Engineering & instrumentation** | Transparent stations with independent cameras, calibrated scales, timestamps and tamper audits | An operational matter-transfer device |
| **Verification & data integrity** | Source IDs, run records, original evidence hashes, controls and review gates | That a green GitHub workflow proves new physics |

## Current program state

**2026-10-22:** research foundation and v0.2 PG-01 architecture merged; source register has 13 bibliographic entries; experiment manifest has **zero conducted runs**. Hardware items are **unselected** and unpurchased; PG-01 is a paper design. No physical transfer tests have occurred.

## Near-term deliverables

1. Resolve project scope, enclosure sizes, measurable sample mass range, data retention policy and power requirements for safe PG-01 instrumentation.
2. Build an engineering bill of materials and trace each component to calibration needs and safety constraints. [Implementation plan](engineering/PG01-IMPLEMENTATION-PLAN.md)
3. Implement local data capture/display using synthetic demo data **clearly isolated** from actual results.
4. Preregister an instrumentation-only null protocol, obtain actual safety approval, then consider calibration of purchased and inspected equipment.
5. Continue literature-critical reviews; only physical hypotheses with quantitative falsifiable predictions merit future special experiments.

## Governance

**Sources → hypothesis → approved protocol → calibration → actual run → original evidence → independent review.** Nothing progresses based on a visually convincing effect alone.
