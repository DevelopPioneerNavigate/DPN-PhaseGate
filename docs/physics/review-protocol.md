# Source-review protocol

**[Physics guide](PHYSICS-COMMAND.md) · [Source registry](../../data/literature/sources.json)**

<img src="../../assets/phasegate-research-pipeline.svg" width="100%" alt="Literature review process"/>

> **Visual interpretation:** Every literature note must separate a primary claim from model assumptions, limits, corrections and unsupported inferences.

---

Record source ID, primary URL, authors, journal, year, DOI (if any), access date, source classification. Extract a **narrow** evidence claim, assumptions, method, uncertainty and explicitly *what the source does not establish*. Compare dissenting studies and corrections. Distinguish preprints, peer-reviewed results, theoretical studies, analogues and institutional explanations. Prefer original sources; never copy a copyrighted paper into Git without permission. Document retractions/updates, and keep interpretations reviewable.
See templates/literature-review.md.
