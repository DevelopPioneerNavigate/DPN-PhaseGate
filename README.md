# DPN PhaseGate

**DPN Technology · Physical Portal Research Program**  
**Research status:** concept and literature review · **Prototype status:** none · **Verified physical-object transfer:** none

**North-star objective:** investigate whether an intact physical object can enter one gateway and emerge from a second gateway, with eventual bidirectional operation. This is **not currently possible with any experimentally demonstrated portal technology**. Quantum teleportation transfers quantum state/information, not macroscopic matter; physical traversable wormholes have not been demonstrated.

This private repository is the source of truth for research questions, citations, hypotheses, decision logs, engineering requirements, experiment protocols, raw-data manifests, safety reviews, and validation checks.

Initial foundation work is being assembled on a review branch. Do not claim a simulation, communications link, optical illusion, or transfer through conventional machinery demonstrates matter teleportation.
